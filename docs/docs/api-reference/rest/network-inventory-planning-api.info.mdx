Advisory network inventory balancing for the warehouse-systems fleet.

Network Inventory Planning projects sibling-context facts (site capability,
site-SKU demand, published capacity) into local read models and proposes
inter-warehouse transfers. It never mutates physical stock: approval,
reservation and physical execution live in their owning contexts.
